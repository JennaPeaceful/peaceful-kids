# Capacitor Quick Reference

> 📚 **Full Documentation**: See `CAPACITOR.md` or `../../capacitor-docs/` for complete guides and API references

## Daily Commands

```bash
# Web Development
npm run dev                    # Start dev server (http://localhost:8080)

# Build & Sync
npm run cap:sync              # Build + sync (production)
npm run cap:sync:dev          # Build + sync (development)

# Open IDEs
npm run cap:open:ios          # Open Xcode
npm run cap:open:android      # Open Android Studio

# Run on Devices
npm run cap:run:ios           # Build + run iOS
npm run cap:run:android       # Build + run Android
```

## Live Reload (Development)

```bash
# 1. Start dev server
npm run dev

# 2. Set server URL (replace with your IP)
export CAP_SERVER_URL=http://192.168.1.100:8080  # Physical device
# OR
export CAP_SERVER_URL=http://localhost:8080      # Simulator only

# 3. Sync and open
npm run cap:sync:dev
npm run cap:open:ios

# 4. When done, disable live reload
unset CAP_SERVER_URL
npm run cap:sync
```

## Platform Detection

```typescript
import { isNativePlatform, isIOS, isAndroid, isWeb } from '@/utils/platform';

if (isNativePlatform()) { /* iOS or Android */ }
if (isIOS()) { /* iOS only */ }
if (isAndroid()) { /* Android only */ }
if (isWeb()) { /* Web browser only */ }
```

## Status Bar Control

```typescript
await hideStatusBar();  // Fullscreen mode
await showStatusBar();  // Normal mode
```

## Troubleshooting

**White screen?**
→ Check `dist/` exists, run `npm run cap:sync`

**Can't connect to dev server?**
→ Check firewall, verify IP address, ensure dev server running

**iOS build issues?**
→ Run `pod install` in `ios/App/`

**Android build issues?**
→ Run `./gradlew clean` in `android/`
